# Кабина — Рукопись

Настольное приложение (macOS) для параллельной работы с текстом: один
фрагмент — сразу несколько вариантов от разных ИИ-моделей, чтобы сравнивать
и выбирать лучший.

## Возможности

- Список глав рукописи и текстовое поле для фрагмента.
- Один клик — параллельный запрос к Claude и Codex.
- Автообновление: приложение само проверяет новые версии и обновляется.

## Требования

Для работы нужны установленные и авторизованные CLI:
- [`claude`](https://claude.com/claude-code) (Claude Code) — своя подписка.
- `codex` — своя подписка ChatGPT.

## Разработка

```bash
pnpm install
pnpm tauri dev
```

Сборка:

```bash
pnpm tauri build
```

## Стек

Tauri v2 (Rust) + React + TypeScript.
