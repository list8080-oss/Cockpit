# Cockpit

Настольное приложение (macOS) для параллельной работы с текстом: один
фрагмент — сразу несколько вариантов от разных ИИ-моделей, чтобы сравнивать
и выбирать лучший.

## Возможности

- Список глав рукописи и текстовое поле для фрагмента.
- Один клик — параллельный запрос к Claude, Codex и Cursor.
- Статус входа и кнопка «Sign in» для каждого движка.
- Настройки: язык интерфейса (en/ru/uk/cs).
- Автообновление: приложение само проверяет новые версии и обновляется.

## Требования

Для работы нужны установленные и авторизованные CLI, каждый на своей подписке:
- [`claude`](https://claude.com/claude-code) (Claude Code).
- `codex` (ChatGPT).
- `cursor-agent` (Cursor).

## Разработка

```bash
pnpm install
pnpm tauri dev
```

Сборка:

```bash
pnpm tauri build
```

## Стек

Tauri v2 (Rust) + React + TypeScript.
